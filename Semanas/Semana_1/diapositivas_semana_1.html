¿Qué es la BI? (Sharda et al.)

Conjunto de estrategias, procesos y tecnologías enfocadas en la creación de conocimiento mediante el análisis de datos organizacionales.

  • Analítica Descriptiva: ¿Qué sucedió? (Reportes históricos)
  • Analítica Predictiva: ¿Qué pasará? (Machine Learning)
  • Analítica Prescriptiva: ¿Qué debemos hacer? (Optimización matemática)

Glosario Técnico de BI

  • ETL (Extract, Transform, Load): El motor de BI. Extraer datos, limpiarlos (Transform) y cargarlos (Load).
  • OLTP vs OLAP: OLTP es para sistemas transaccionales (Caja registradora), OLAP para consultas analíticas complejas (Cubos de datos).
  • Data Warehouse: Repositorio centralizado de datos estructurados de toda la empresa.
  • Data Mart: Un "mini" Warehouse enfocado en un solo departamento (ej. Solo Finanzas).

Storytelling with Data (Knaflic)

  1. Decluttering (Limpieza Visual): Elimina bordes, gridlines gruesas, y sombras que sobrecargan la mente (Carga Cognitiva).
  2. Gestalt (Proximidad): Agrupa visualmente los KPIs que comparten temática (ej. Ingresos y Costos juntos).
  3. Atención Dirigida: Usa color vibrante (Naranja UNAB) SOLO para resaltar alertas. Usa grises y azules marinos para lo normal.
  4. Cero Gráficos 3D: Distorsionan la percepción geométrica (Nunca uses 3D Pie Charts).

Conclusiones

  • El BI es Estratégico: No se trata de dominar la herramienta técnica (SQL/Power BI), sino de usar los datos descriptivos para tomar decisiones prescriptivas.
  • El Diseño Importa: Un Data Warehouse perfecto con consultas instantáneas puede fracasar si el Dashboard que lo presenta está saturado e incomprensible (Clutter).
  • Contexto de Negocio: Un KPI (Key Performance Indicator) solo tiene sentido si está alineado a un objetivo del negocio (Aumentar Ventas, Reducir Costos).
