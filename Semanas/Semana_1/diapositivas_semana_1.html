¿Qué es la BI? (Sharda et al.)

Conjunto de estrategias, procesos y tecnologías enfocadas en la creación de conocimiento mediante el análisis de datos organizacionales.

  • Analítica Descriptiva: ¿Qué sucedió? (Reportes)
  • Analítica Predictiva: ¿Qué pasará? (Machine Learning)
  • Analítica Prescriptiva: ¿Qué debemos hacer? (Optimización)

Glosario Técnico de BI

  • ETL (Extract, Transform, Load): El motor de BI. Extraer datos, limpiarlos (Transform) y cargarlos (Load).
  • OLTP (Online Transaction Processing): Sistemas de transacciones rápidas diarias (Ej. Caja Registradora, ERP). No sirven para analizar grandes volúmenes de historia.
  • OLAP (Online Analytical Processing): Sistemas diseñados para consultas analíticas complejas y multidimensionales.
  • Data Warehouse: Repositorio centralizado de datos estructurados de toda la empresa.
  • Data Mart: Un "mini" Data Warehouse enfocado en un solo departamento (ej. Solo Finanzas).

Storytelling with Data (Knaflic)

Para dejar de hacer "gráficos básicos" y crear Dashboards de alto impacto:

  1. Decluttering: Elimina TODO el desorden (bordes, gridlines gruesas, fondos grises).
  2. Gestalt (Proximidad): Agrupa los KPIs relacionados visualmente.
  3. Atención Dirigida: Usa color fuerte (ej. naranja UNAB) SOLO para resaltar el dato clave; el resto debe ser neutro (gris/azul oscuro).
  4. Cero Gráficos 3D: Distorsionan la percepción visual de los datos, especialmente los *Pie charts*.

Anatomía de un Dashboard

Dashboard Malo

  • Uso excesivo de colores brillantes (Arcoíris).
  • Gráficos de torta en 3D.
  • Ausencia de jerarquía (ojos no saben a dónde mirar).
  • Etiquetas de ejes redundantes.

Dashboard Excelente

  • KPIs principales (Ingresos, Costos) arriba a la izquierda.
  • Paleta de 2 colores (Azul corporativo y un color de alerta).
  • Diseño limpio sin bordes de celdas pesados (Declutter).
  • Gráficos de barras horizontales ordenados de mayor a menor.
