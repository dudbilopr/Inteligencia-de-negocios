Evolución Histórica

timeline title Historia del BI 1980s : Sistemas de Soporte a Decisiones (DSS) : Reportes estáticos IT 1990s : Data Warehousing (Bill Inmon) : OLAP y Minería de Datos 2000s : BI Tradicional : Dashboards corporativos pesados 2010s : Self-Service BI : Tableau, Power BI : Democratización de datos 2020s : Augmented BI : IA Generativa, Predicciones en tiempo real

Cuadro Sinóptico: Arquitectura Base

  • Fuentes (OLTP): Datos sucios, ERP, Excel, Cajas registradoras. Hechos para rapidez, no para análisis.
  • ETL: Extraer, Transformar y Cargar. El paso más doloroso pero el más importante.
  • Data Warehouse: Repositorio limpio y estructurado (OLAP).
  • Visualización: Power BI / Dashboards interactivos.
