Laboratorio: Python Avanzado dentro de Power BI

Objetivo Táctico: Hay gráficos estadísticos profundos que BI no soporta nativamente. Como analista de datos avanzado, escribirás código en Seaborn (Python) para generar un Mapa de Calor (Heatmap) de correlaciones de Pearson, incrustado en el dashboard operativo.

Flujo de Implementación Técnica

1

Configuración del Entorno (Python Runtime)

Asegurar que Python y Pandas/Matplotlib/Seaborn estén instalados y mapeados en las opciones globales del software BI (Options > Python Scripting).

2

Transformación ETL con Pandas

En Power Query, seleccionar 'Ejecutar script de Python'. Extraer el año y mes de una fecha compleja utilizando las potentes funciones lambda y de string de Pandas: `dataset['Año'] = dataset['Fecha_Cruda'].str.extract(r'(\d{4})')`.

3

Visualización de Correlaciones (Heatmap)

Arrastrar el visual de Python al lienzo. Añadir métricas numéricas continuas (Ventas, Temperatura_Clima, Descuentos). Escribir el script: `import seaborn as sns; import matplotlib.pyplot as plt; sns.heatmap(dataset.corr(), annot=True, cmap='Blues'); plt.show()`.

Actividad Autónoma

Reto Arquitectónico Avanzado

Entrenar y serializar (joblib/pickle) un modelo simple de Random Forest Regressor en Jupyter Notebook externo. Importarlo dentro de Power Query para realizar predicciones dinámicas y crear una columna calculada predictiva.

Criterio de Evaluación Institucional: Este reto exige aplicar la documentación oficial, foros de la comunidad técnica y fundamentos teóricos de la clase magistral. Asegúrate de comentar y estructurar bien tu código DAX o M para sustentarlo en la revisión.
