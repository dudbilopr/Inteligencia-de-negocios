Antes de empezar

Abra la consulta de la sesión 3 con Online_Retail.xlsx y actívele el perfilado sobre todo el conjunto de datos. Chen, D. (2015). UCI, CC BY 4.0. El significado de cada columna está en la guía de la sesión 3.

Vaya llenando su bitácora mientras trabaja, no al final:

1. Fijar los tipos

10 minutos.

  1. Fije cada tipo haciendo clic en el icono de la columna: InvoiceNo, StockCode, Description y Country como texto; Quantity y CustomerID como número entero; InvoiceDate como fecha y hora; UnitPrice como número decimal.
  2. Revise la calidad de cada columna. ¿Alguna tiene errores?
  3. ¿Por qué CustomerID es un número y aun así no conviene sumarlo?
Punto de control

Siguen 541.909 filas y ninguna columna debe mostrar errores. Si InvoiceNo queda como número, las facturas con C dan error. CustomerID es un identificador: sumarlo no significa nada.

2. Excluir lo que no es venta ni cancelación

15 minutos.

Regla: se conservan las cancelaciones, y las demás filas solo si tienen cantidad y precio positivos.

  1. Antes de filtrar, anote el conteo de Quantity menor o igual a 0 que no sea cancelación, filtrando y deshaciendo. ¿Qué dice Description en esas filas?
  2. Use Inicio > Mantener filas > o escriba el filtro en la barra de fórmulas con este paso:
= Table.SelectRows(#"Paso anterior", each Text.StartsWith([InvoiceNo], "C") or ([Quantity] > 0 and [UnitPrice] > 0))
  1. Reemplace #"Paso anterior" por el nombre de su último paso. Agregue un paso con el botón fx.
  2. Cuente las filas: Transformar > Contar filas. Anote el número y elimine ese paso de conteo.
Punto de control

Quedan 539.392 filas: salen 2.517. Casi todas tienen precio cero y notas como check o damaged; también salen 2 ajustes con precio negativo. Si le quedan muchas menos, escribió and en lugar de or y perdió las cancelaciones.

3. Corregir lo que está mal escrito

10 minutos.

  1. Seleccione StockCode y use Transformar > Formato > MAYÚSCULAS.
  2. Seleccione Description y use Transformar > Formato > Recortar.
  3. Con el perfil sobre todo el conjunto, lea cuántos valores distintos tiene StockCode ahora.
  4. ¿Conviene poner Description en mayúsculas? Mire Manual y Next Day Carriage antes de decidir.
Punto de control

StockCode: 3.828 valores distintos en las filas que quedaron, frente a 3.938 antes de pasar a mayúsculas. Son 110 códigos que solo diferían en la letra. Sigue en 539.392 filas.

4. Marcar lo que importa distinguir

15 minutos.

  1. Agregar columna > Columna personalizada. Nombre: Importe. Fórmula: [Quantity] * [UnitPrice]. Fije el tipo número decimal.
  2. Otra columna, Tipo: if Text.StartsWith([InvoiceNo], "C") then "Cancelación" else "Venta".
  3. Otra, Clase, para separar lo que no es mercancía:
if List.Contains({"POST","DOT","M","B","C2","D","CRUK","S","AMAZONFEE","BANK CHARGES","PADS"}, [StockCode]) then "No producto" else "Producto"
  1. Agregue Fecha: seleccione InvoiceDate y use Agregar columna > Fecha > Solo fecha.
  2. No rellene los clientes vacíos con un número inventado. Anote en su bitácora qué decidió hacer con ellos.
Punto de control

Filas con Tipo Venta: 530.104. Cancelación: 9.288. Clase No producto: 2.899 filas, con importe neto de −£23.522,64. Ese neto pequeño esconde mucho: los envíos suman +£272.476 (POST y DOT) y las comisiones de Amazon restan −£221.520. Por eso conviene marcarlas y no borrarlas.

6. Romper y arreglar

15 minutos. Hágalo sobre una copia: clic derecho en la consulta y Duplicar.

  1. Seleccione solo InvoiceNo y use Inicio > Quitar filas > Quitar duplicados. ¿Cuántas filas quedan? ¿Cuánto da ahora la suma de Importe?
  2. Elimine ese paso. Haga clic en un paso anterior y arrastre Importe por encima de donde se calcula: ¿qué mensaje aparece? Deshágalo.
  3. Cambie el nombre de Quantity en el primer paso, para simular que la fuente cambió. Vaya al último paso: ¿dónde está el error y cómo lo ubica?
  4. Escriba en dos líneas cómo encontraría estos errores en sus propios datos.
Punto de control

Quitando duplicados solo por InvoiceNo queda una fila por factura: 23.796, y el total deja de cuadrar. Es el error más común de este botón.

Un paso que usa una columna renombrada falla con un mensaje que nombra la columna. Se recorre el panel de pasos hasta hallar el primero con error.

7. Su proyecto: limpieza y bitácora

Es lo que se entrega. Continúa como trabajo independiente.

  1. Tome su ficha de diagnóstico de la sesión 3. Para cada hallazgo, decida: excluir, corregir, marcar o dejar.
  2. Aplíquelo en Power Query, con nombres de paso claros. Clic derecho en un paso > Cambiar nombre.
  3. Defina un total de control antes de empezar, y concilie al final.
  4. Escriba la bitácora, con al menos cinco filas y la columna “Qué podría estar mal” completa.
  5. Lleve a la tutoría: ¿sus datos permiten responder su pregunta? Anote el acuerdo.

Tutoría de viabilidad

  • Fuente: ¿existe, es accesible y tiene licencia o permiso?
  • Pregunta: ¿las columnas permiten responderla?
  • Volumen y periodo: ¿alcanzan para comparar?
  • Calidad: ¿lo que falta impide la decisión?

Consulta completa, para comparar

En Inicio > Editor avanzado. Cambie la ruta del archivo por la suya.

let
    Origen = Excel.Workbook(File.Contents("C:\Datos\Online_Retail.xlsx"), null, true),
    Hoja = Origen{[Item="Online Retail",Kind="Sheet"]}[Data],
    Encabezados = Table.PromoteHeaders(Hoja, [PromoteAllScalars=true]),
    Tipos = Table.TransformColumnTypes(Encabezados, {
        {"InvoiceNo", type text}, {"StockCode", type text}, {"Description", type text},
        {"Quantity", Int64.Type}, {"InvoiceDate", type datetime}, {"UnitPrice", type number},
        {"CustomerID", Int64.Type}, {"Country", type text}}),
    SoloValidas = Table.SelectRows(Tipos, each Text.StartsWith([InvoiceNo], "C")
        or ([Quantity] > 0 and [UnitPrice] > 0)),
    Mayus = Table.TransformColumns(SoloValidas, {{"StockCode", Text.Upper, type text}}),
    Recorte = Table.TransformColumns(Mayus, {{"Description", Text.Trim, type text}}),
    Importe = Table.AddColumn(Recorte, "Importe", each [Quantity] * [UnitPrice], type number),
    Tipo = Table.AddColumn(Importe, "Tipo", each if Text.StartsWith([InvoiceNo], "C")
        then "Cancelación" else "Venta", type text),
    Clase = Table.AddColumn(Tipo, "Clase", each if List.Contains({"POST","DOT","M","B","C2",
        "D","CRUK","S","AMAZONFEE","BANK CHARGES","PADS"}, [StockCode])
        then "No producto" else "Producto", type text),
    Fecha = Table.AddColumn(Clase, "Fecha", each DateTime.Date([InvoiceDate]), type date)
in
    Fecha
