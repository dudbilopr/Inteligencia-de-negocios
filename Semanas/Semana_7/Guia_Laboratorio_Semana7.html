Inteligencia de Negocios • Semana 7

Laboratorio: Diseño de una App Analítica Interactiva

Objetivo Táctico: Vamos a transformar un reporte estático y aburrido en una aplicación web analítica (App-like). Incorporaremos menús de navegación laterales, ventanas emergentes dinámicas y exploración profunda para analizar las causas raíz de la pérdida de rentabilidad.

Flujo de Implementación Técnica

1

Configuración de un Report Page Tooltip

Crear una nueva página, configurar el lienzo a tamaño 'Información sobre herramientas'. Diseñar un mini-gráfico de tendencia temporal. Enlazar esta página a los gráficos de barras de la página principal para visualizar la tendencia mensual al posar el mouse.

2

Implementación de Menú de Navegación

Ocultar las pestañas estándar del reporte. Diseñar una barra lateral oscura usando formas rectangulares, importar iconos SVG y asignar 'Acciones de Navegación de Página' para emular el flujo de un sitio web.

3

Desarrollo de Drill-through

Crear la página 'Ficha del Empleado'. Configurar la ranura de obtención de detalles insertando el campo 'Nombre_Empleado'. Añadir un botón automático de retroceso (Back button). Testear el salto de página.

Actividad Autónoma

Reto Arquitectónico Avanzado

Diseñar un menú colapsable tipo 'Hamburguesa' utilizando el panel de Selección y Marcadores (Bookmarks) para mostrar u ocultar un panel de filtros avanzado mediante transiciones suaves sin ocupar espacio en el lienzo principal.

Criterio de Evaluación Institucional: Este reto exige aplicar la documentación oficial, foros de la comunidad técnica y fundamentos teóricos de la clase magistral. Asegúrate de comentar y estructurar bien tu código DAX o M para sustentarlo en la revisión.
