Laboratorio: Transformación de Datos y Primeras Medidas

Objetivo Táctico: En esta práctica, simularemos un entorno empresarial real donde recibiremos datos caóticos de ventas de múltiples sucursales. Tu labor es limpiar y estructurar los datos usando Power Query (Lenguaje M) y crear las medidas fundacionales (Revenue, Cost, Margin) utilizando DAX.

Flujo de Implementación Técnica

1

Limpieza y Estandarización en Power Query

Importar el dataset de ventas. Identificar y eliminar duplicados. Rellenar valores nulos (Fill Down) y usar columnas condicionales para normalizar los nombres de las ciudades y corregir errores tipográficos en las categorías de productos.

2

Modelado Dimensional

Cargar las tablas limpias a Power BI. Establecer relaciones 1 a muchos (1:*) entre la tabla de Ventas (Hechos) y las tablas de Clientes y Productos (Dimensiones). Ocultar las llaves foráneas para no confundir al usuario final.

3

Creación del Framework DAX

Crear una tabla vacía dedicada a 'Métricas_Base'. Construir las siguientes medidas DAX usando iteradores seguros:
Total_Ventas = SUMX(Ventas, Ventas[Cantidad] * Ventas[Precio_Unitario])
Margen_Porcentual = DIVIDE([Total_Ventas] - [Costo_Total], [Total_Ventas], 0)

Actividad Autónoma

Reto Arquitectónico Avanzado

Construir una columna condicional en Power Query que clasifique el nivel de ingresos de los clientes basado en su salario, y luego crear una medida en DAX que calcule el % de participación de cada segmento sobre las ventas totales.

Criterio de Evaluación Institucional: Este reto exige aplicar la documentación oficial, foros de la comunidad técnica y fundamentos teóricos de la clase magistral. Asegúrate de comentar y estructurar bien tu código DAX o M para sustentarlo en la revisión.
