1. Conectar el Excel

10 minutos.

  1. En Power BI Desktop, vaya a Inicio > Obtener datos > Libro de Excel y elija Online_Retail.xlsx.
  2. Marque la hoja Online Retail. Elija Transformar datos, no Cargar: así se abre Power Query.
  3. Mire el panel Pasos aplicados. ¿Qué pasos creó Power BI sin que usted se lo pidiera?
  4. Abajo a la izquierda, lea cuántas columnas y filas dice que tiene.
  5. Revise el icono de tipo en cada columna. ¿InvoiceNo quedó como texto o como número? Si quedó como número, las facturas con C darán error: cámbiela a texto y elija Reemplazar actual.
Punto de control

8 columnas. El contador suele decir “999+ filas” mientras no se cargue todo; el total real es 541.909, y lo comprobará en el ejercicio 2. Los pasos automáticos suelen ser Origen, Navegación, Encabezados promovidos y Tipo cambiado.

2. Perfilar todo el archivo

15 minutos.

  1. Vaya a Vista y active Calidad de columna, Distribución de columnas y Perfil de columnas.
  2. Lea el porcentaje de vacíos de CustomerID. Anótelo.
  3. Abajo a la izquierda, haga clic en Generación de perfiles de columnas basada en 1000 filas superiores y cambie a todo el conjunto de datos. Espere.
  4. Lea otra vez el mismo porcentaje. ¿Cuánto cambió?
  5. Seleccione Country y lea en el perfil cuántos valores distintos hay. Haga lo mismo con InvoiceDate: mínimo y máximo.
  6. Seleccione Quantity y UnitPrice. Lea el mínimo y el máximo. ¿Algo es imposible?

3. Buscar lo que no se ve

20 minutos. Filtre, mire y deshaga con la X del paso; todavía no limpia nada.

  1. Cancelaciones. Filtre InvoiceNo con Filtros de texto > Comienza por y la letra C. Lea el conteo en el perfil.
  2. Precios raros. Filtre UnitPrice a menor o igual que 0. ¿Qué dice Description en esas filas?
  3. Mayúsculas. Busque en StockCode el código 15056BL y luego 15056bl. ¿Son el mismo producto?
  4. Países. En el perfil de Country, ubique EIRE, RSA, Unspecified y European Community. ¿Qué significa cada uno?
  5. Semana. Agregue una columna con Agregar columna > Fecha > Día > Nombre del día sobre InvoiceDate y mire su distribución. ¿Falta algún día?
  6. Elimine los pasos de prueba del panel para dejar la consulta como estaba.
Punto de control
  • Cancelaciones: 9.288 filas.
  • Precio cero: 2.515 filas, con notas como check, damaged, ? o found. Precio negativo: 2 filas de ajuste contable.
  • 15056BL aparece en minúsculas y mayúsculas: es el mismo código escrito de dos formas. Hay 4.070 códigos distintos, y 3.958 sin distinguir mayúsculas.
  • EIRE es Irlanda; RSA, Sudáfrica. Unspecified no se puede asignar.
  • No hay ninguna fila en sábado. Los datos no dicen por qué; no es un error de archivo.

4. Conectar un CSV y una API

20 minutos.

CSV

  1. Inicio > Nuevo origen > Texto/CSV, elija Resenas_Amazon.csv. Confirme delimitador coma y origen UTF-8.
  2. Compruebe que queden 2 columnas y 1.000 filas, y que las tildes y símbolos se lean bien.

API de la TRM

  1. Inicio > Nuevo origen > Web. Pegue esta dirección y elija acceso anónimo:
https://www.datos.gov.co/resource/32sa-8pi3.json
  1. Se abre una lista de registros. Pulse A la tabla y expanda la columna con el botón de flechas.
  2. Mire cuántas filas trajo y el tipo de la columna valor. Anótelo.
  3. Cambie el tipo de valor a número decimal. Si salen errores, use Cambiar tipo > Usando configuración regional e inglés (Estados Unidos), porque el dato trae punto decimal.
  4. Ahora vaya a Origen y agregue esto al final de la dirección: ?$limit=10000. ¿Cuántas filas hay ahora?
Punto de control

La API entrega 1.000 registros si no se le pide otra cosa, y la tabla tiene más de 8.000. Otra vez: mirar solo una parte parece mirar todo. El total crece cada día, así que su cifra puede ser mayor que 8.382, la que había cuando se escribió esta guía.

El campo valor llega como texto. Si no se convierte, no se puede promediar.

5. Diagnóstico de sus datos

45 minutos. Es lo que se entrega. Sirve de base para el Proyecto 1.

Conecte los datos de su proyecto y llene la ficha con cifras, sobre todo el conjunto de datos. Si sus datos no son viables, dígalo: es el mejor momento para cambiarlos, y hay tutoría para revisarlo.

CampoQué escribir
FuenteNombre, enlace, autor o dueño, licencia o permiso.
TamañoFilas, columnas y qué representa una fila.
CompletoQué columnas tienen vacíos y cuántos. ¿Vacío significa cero, desconocido o no aplica?
Único¿Hay filas repetidas? ¿Cuál debería ser la columna única?
VálidoValores imposibles: negativos, fechas futuras, texto donde va número.
ConsistenteLo mismo escrito de dos formas: categorías, ciudades, mayúsculas.
CubreFecha mínima y máxima. ¿Hay meses incompletos? ¿A quién deja por fuera?
Viabilidad¿Estos datos permiten responder su pregunta analítica de la sesión 2? ¿Qué le falta?

No borre ni corrija nada todavía: en la sesión 4 decidirá qué hacer con cada hallazgo y lo justificará.

Conectar una base de datos

Para consultar cuando su proyecto use una base de datos.

Con Obtener datos > Base de datos, Power BI suele pedir el servidor, el nombre de la base y el modo de conexión. Use Importar, salvo que tenga una razón para DirectQuery. Pida las credenciales al dueño de los datos, no las escriba en el informe y no las comparta.

En la sesión 6 consultará una base SQLite real con SQL.
