Historia y Origen de las Herramientas

Power Query (2013)

Nació bajo el nombre código "Data Explorer" para democratizar el ETL en Excel sin requerir código SQL complejo ni intervención directa de IT.

VertiPaq Engine (2010)

Diseñado por Microsoft para SQL Server Analysis Services (SSAS) e integrado inicialmente en PowerPivot. Permite una ultra compresión en memoria.

DAX (2010)

Lenguaje basado en expresiones de Excel creado específicamente para operar sobre matrices relacionales en memoria, potenciando PowerPivot y luego Power BI.

¿Por qué se usan?

Para pasar de procesos manuales propensos al error (Copiar y Pegar) a pipelines de datos 100% automatizados, comprimidos e instantáneos.

Referencia: learn.microsoft.com/power-bi/transform-model/

Arquitectura VertiPaq: Columnar vs Fila

¿Por qué se usa?

VertiPaq comprime columnas creando diccionarios de valores únicos. Permite consultar millones de registros en milisegundos usando solo memoria RAM.

Tip de Alto Nivel (Regla de Oro)

"Eliminar columnas innecesarias o de alta cardinalidad (como Transaction_ID) ahorra hasta un 80% más memoria RAM que eliminar miles de filas."

Anatomía del Lenguaje M (Caso Real)

El Bloque let ... in

Cada paso en M se declara como un identificador inmutable. El paso siguiente referencia al nombre del paso anterior.

  • let: Define las variables/pasos de transformación.
  • in: Declara cuál paso se entregará como resultado final de la tabla.
  • M es estrictamente Case-Sensitive.

// Limpieza de Ventas_Retail_Sucio.csv

let
    Origen = Csv.Document(File.Contents("Ventas_Retail_Sucio.csv"), [Delimiter=";", Encoding=65001]),
    
    Encabezados = Table.PromoteHeaders(Origen, [PromoteAllScalars=true]),
    
    TextoLimpio = Table.TransformColumns(Encabezados, {{"Ciudad_Origen", Text.Trim, type text}}),
    
    ReemplazoBGA = Table.ReplaceValue(TextoLimpio, "BGA", "Bucaramanga", Replacer.ReplaceText, {"Ciudad_Origen"})
in
    ReemplazoBGA

DAX: Contexto de Fila vs Contexto de Filtro

Row Context

Contexto de Fila

La conciencia de "en qué fila estoy actualmente" iterando tabla por tabla.

  • Existe automáticamente en Columnas Calculadas.
  • Generado manualmente por Iteradores (ej. SUMX).
  • Diferencia Clave: Sabe qué fila evalúa, pero NO calcula subtotales o totales globales basados en el lienzo visual.

Filter Context

Contexto de Filtro

El conjunto de filtros aplicados externamente a los datos subyacentes.

  • Determinado por los filtros activos en la interfaz (Slicers, Clics, Matrices).
  • Aplica siempre sobre las Medidas (Measures).
  • Diferencia Clave: Restringe la tabla origen de datos ANTES de que DAX realice cualquier operación agregada.

Agregadores (SUM) vs Iteradores (SUMX)

Error de Sintaxis (SUM)

Tot = SUM(Unidades_Vendidas * Precio_Unitario_USD)

SUM exige UNA sola columna. No puede multiplicar fila por fila porque carece de Contexto de Fila.

Correcto (SUMX)

Tot = SUMX(Fact_Ventas, Unidades_Vendidas * Precio)

SUMX abre un Contexto de Fila temporal en memoria RAM.

Tip de Alto Nivel: Usa SUM para columnas únicas precalculadas; usa SUMX solo cuando requieras multiplicaciones o lógicas dinámicas multi-columna.

CALCULATE & Transición de Contexto

Caso 1: Modificar Filtros

Caso 2: Transición de Contexto

Al invocar una [Medida] dentro de una Columna Calculada (Row Context), DAX automáticamente envuelve la medida en un CALCULATE invisible, transformando la fila en un filtro equivalente.

Reto ETL: Limpiando Ventas_Retail_Sucio.csv

Columna: Precio_Unitario_USD

Problema: 190 filas usan coma europea como decimal (Ej. 1322,09 en lugar de 1322.09), rompiendo el tipado.

Acción: Reemplazar valores (,) por (.) y re-tipar.

Columna: Unidades_Vendidas

Problema: 99 valores capturados en negativo debido a errores de sistema en devoluciones.

Acción M: Aplicar función Number.Abs (Valor Absoluto).

Columna: Descuento_Aplicado

Problema: 89 valores dicen el texto "N/A", lo que impide convertir la columna a Porcentaje.

Acción M: Reemplazar "N/A" con null y tipar Porcentaje.

Columna: Cliente_Nombre

Problema: Duplicidad semántica: "Acme SAS", "Acme sas ", "Bio-Health", "Bio Health".

Acción M: Limpiar espacios (Text.Trim), Poner en mayúsculas cada palabra (Text.Proper) y reemplazar sintaxis.
