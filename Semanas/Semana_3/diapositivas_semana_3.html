Conceptos Analíticos Clave

M, el lenguaje de Power Query

Lenguaje funcional utilizado para transformar, filtrar y limpiar datos (ETL) antes de ser cargados al modelo. Es case-sensitive.

Clic para profundizar

Contexto de Evaluación (DAX)

El corazón de DAX. Determina qué filas de la base de datos están 'activas' al calcular una fórmula. Se divide en Contexto de Fila (iteración) y Contexto de Filtro (segmentación).

Clic para profundizar

Profundización: Columnas Calculadas vs Medidas

Columnas Calculadas

Se calculan fila por fila en el momento en que se actualizan los datos (Contexto de Fila). Aumentan el tamaño del archivo (.pbix) y consumen memoria RAM estática. Útiles para agrupar o crear nuevas categorías para segmentar (e.g., 'Rango de Edad').

Medidas (Measures)

Se calculan en tiempo real según los filtros activos en el dashboard (Contexto de Filtro). No consumen memoria RAM de almacenamiento físico, sino capacidad de procesamiento (CPU) al interactuar. Son obligatorias para métricas analíticas (e.g., Margen Neto, Ventas YTD).
